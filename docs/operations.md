# Operations

## Install agents

- Open **Settings → Marketplace**.
- Install:
  - `easySTT` for voice-to-text utility.
  - `OpenRouter Agent` for AI chat.
  - `Cloud.ru Agent` for Cloud.ru provider lane.

## Start / stop agents

- From agent card: `Start` / `Stop`.
- From command palette: type `start` / `stop`.
- From tray quick action: `New chat (last AI)` opens chat quickly.

## Back up conversations

- Open an AI chat.
- Click `Export` in chat header.
- Hub writes:
  - Markdown export (`.md`)
  - Full JSON export (`.json`)
  into app data `exports` directory.

## Update app

- Open **Settings → About**.
- Click **Check for updates**.
- If update is found, it will be downloaded and applied on restart.

## First-run onboarding

If no agents are detected, hub shows a guided onboarding block with one-click installs.
